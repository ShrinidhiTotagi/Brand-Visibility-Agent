Agent v2 - Autonomous Self-Learning Intelligence
AI Search Brand Visibility Autonomous Intelligence Agent

Purpose: Continuously monitors brand visibility across AI search systems without manual clicks. The agent collects data, validates evidence, analyzes, compares with previous results, detects changes, learns from approved feedback, and re-runs analysis on schedule or when major changes occur.

Autonomy: Agent loop + scheduler (STARTUP / DAILY / WEEKLY runs), job queue with per-job failure isolation and configurable retries, automatic re-analysis on website content changes.

Data Sources: Manual entry, CSV import, built-in website scraper (real HTTP extraction), historical analysis, user feedback. External discovery / AI-search APIs show "NOT CONNECTED" until configured - never fabricated.

Scoring: Deterministic, explainable 5-component readiness score (Profile 20% / Keywords 25% / Competitors 20% / Content 20% / AI-readiness 15%). Observed AI-search metrics are reported separately and are never mixed with estimates.

Learning: Persistent query memory, evidence-based content change detection, learning memory of approved feedback and historical patterns. Recommendations rated "Already Implemented" are not repeated without new contradicting evidence.
